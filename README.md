# pi-loop

Pi 扩展：**死循环无限自我迭代**。

激活后循环不会因为任何自身原因停下来——模型说"做完了"、提问、请求确认、
请求出错、被 Esc 中断、扩展到重载、甚至进程被强杀，都会自动继续。
唯一能停下来的方式是用户显式执行 `/loop-off` 或 `/loop-off-now`。

## 命令

| 命令            | 行为                                                                                        |
| --------------- | ------------------------------------------------------------------------------------------- |
| `/loop [目标]`  | 激活死循环。空闲时立即开始第 1 轮；流式运行中则在本轮结束时接管。带参数可随时更新长期目标。 |
| `/loop-off`     | 在下一个里程碑停止：让当前轮自然跑完，然后停止。                                            |
| `/loop-off-now` | 立即停止：中止当前运行，取消一切待执行的重启，清除循环状态。                                |

## 底部状态栏

```
∞ loop #12        运行中（#12 为已开始的迭代轮数）
∞ loop #12 ↻      运行已结束/被中断，正在自动重新点火
∞ loop #12 ⚠      最近 1 轮以上没有任何工具调用，正在推动模型产生真实动作
∞ loop #12 收尾中  已执行 /loop-off，等待本轮里程碑
```

## 为什么停不下来

| 触发情况                     | 处理                                                             |
| ---------------------------- | ---------------------------------------------------------------- |
| 模型自然结束、反问、请求确认 | `agent_before_settle` 返回 `continue: true` 并注入下一轮指令     |
| 模型请求出错                 | 不停止；5s → 10s → … → 封顶 60s 退避后继续，并要求模型先诊断错误 |
| 用户 Esc / 中断当前运行      | `agent_settled` 后自动重新点火（延迟 1s，失败时退避到 30s）      |
| 边界无法继续 / 运行异常结束  | `agent_settled` 后自动重新点火                                   |
| 扩展运行时重载               | 新运行时从会话记录恢复状态后自动继续                             |
| 进程退出 / 被强杀            | 下次用 `--continue` 恢复该会话时自动继续迭代                     |
| 运行卡死但状态仍是空闲       | 看门狗每 15s 检查一次，发现"已激活但没有运行"就重新点火          |

## 迭代指令

每轮注入的内容：

- 立即执行当前最高价值的下一步，不征求许可、不只复述计划、不以提问结束；
- 本轮必须有真实产出（文件修改 / 命令执行 / 验证结果），纯文字回复不算迭代；
- 完成后自我验证并记录结果，然后继续下一轮；
- 只有 `/loop-off` 或 `/loop-off-now` 才能结束循环。

只有最后一条迭代指令会进入模型上下文（旧的会被 `context` 钩子裁掉），
循环关闭后所有迭代指令都会从上下文中移除，不会污染后续对话。

## 状态持久化

循环状态（phase / 目标 / 轮数）通过 `pi.appendEntry("pi-loop-state", ...)` 写入会话。
恢复会话（含进程重启 / 强杀后 `--continue`）时若循环仍处于激活状态，
会在状态栏显示 `↻` 并自动开始下一轮，不需要任何用户输入。

## 安装

```
# 用户级（所有项目可用）
~/.pi/agent/extensions/pi-loop/index.ts

# 项目级
<项目>/.pi/extensions/pi-loop/index.ts
```

或直接指定加载：

```bash
pi --extension ./pi-loop
```
